É um buscador para você usar o de base para o seu buscador todos os resultados 
Ele é um alternativo ao serviço do Google ou do Bing para conseguir resultados de pesquisa opositor é totalmente de código aberto 
Aonde você pode colocar o link do seu site ou colocar novos links dentro do positório
Cada de cada site é sal dentro de um arquivo .xml
## Como que funciona o projeto 
Oferecemos uma base de links da internet para você usar no seu buscador online onde oferece milhões de links para você colocar no seu buscador gratuitamente 
Outras pessoas o criador de sites pode colocar seus links aqui no positório 
Você pode baixar opositório e colocar no servidor local 
Oferecemos bastante links para o seu buscador 
## Treinamento de modelos
Ajudar as pessoas quer treinar seus modelos de IA oferecemos milhões de links para você acessar e baixar o conteúdo desse site

Eu estou fazendo isso porque eu gosto e eu quero que no futuro outras pessoas podendo tirar suas próprias buscadores online dentro da internet
